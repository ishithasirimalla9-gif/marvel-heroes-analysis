# 🦸 Marvel Heroes Power BI Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard created to analyze Marvel heroes based on their character attributes, powers, affiliations, and overall statistics.

The dashboard provides an interactive way to explore and compare different Marvel heroes using visualizations, filters, and KPIs.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel / CSV
- GitHub

## 📁 Dataset

The dataset used for this project is the **Marvel Heroes** dataset.

The dataset contains information about Marvel characters and their attributes, which are used to perform character-level analysis and comparisons.

## 📈 Dashboard Analysis

The dashboard includes analysis such as:

- 🦸 Marvel heroes overview
- ⚡ Character power statistics
- 💪 Strength and intelligence comparison
- 🏆 Top-performing heroes
- 👨‍🦸 Hero distribution
- 👩‍🦸 Gender analysis
- 🌎 Character affiliations
- 📊 Interactive hero comparisons

## 🎯 Key Features

- Interactive slicers and filters
- KPI cards
- Character comparison
- Power and attribute analysis
- Dynamic visualizations
- Interactive Power BI dashboard
